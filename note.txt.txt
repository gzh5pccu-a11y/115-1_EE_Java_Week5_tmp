6-2
- Java 的類別其實有兩種，一種是內建的叫做內建類別，另外一種是你自己設計的，就叫做自訂類別。
- 就算是你自己設計的類別(自訂類別)也可以有靜態方法以及非靜態方法的不同設計
- 靜態方法的定義(就是設計的意思) 前面要加一個 static 保留字，使用的時候可以直接以原始類別的名稱直接呼叫

6-17
- 字串類別常用方法，從這裡開始，課本就是在示範: Java 內建類別的非靜態方法的使用範例。
- 有別於靜態方法 (static method)，非靜態方法的英文表示為: instance method
- 使用非靜態方法之前，先 new 出某個類別的 object (物件)，然後就用這個 object去呼叫屬於那個類別之下的 method
- String str = keyin.nextLine(); 這一行的意思就是:藉由輸入的字串，摻生一個 String 物件，這個物件的名稱就是 str
